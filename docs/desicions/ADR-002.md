# ADR 002: Uso de `std::unordered_map` para la Gestión de Suscriptores

## Estado
Aceptado

## Contexto
El sistema necesita mapear un identificador único de evento hacia una colección de funciones de respuesta (callbacks).

## Decisión
Hemos decidido utilizar la estructura `std::unordered_map<EventType, std::vector<Callback>>`.

## Justificación
- **Complejidad Temporal**: `std::unordered_map` proporciona una complejidad promedio de $O(1)$ para la búsqueda, asegurando que la publicación de un evento sea rápida independientemente de la cantidad de tipos de eventos registrados.
- **Eficiencia de Iteración**: `std::vector` proporciona memoria contigua, que es la forma más eficiente de iterar sobre la lista de suscriptores durante la publicación de un evento.

## Consecuencias
- **Uso de Memoria**: Los mapas de hash consumen más memoria que los arreglos simples o las listas para mantener la estructura de la tabla hash.
