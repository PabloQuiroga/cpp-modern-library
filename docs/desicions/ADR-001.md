# ADR 001: Uso de `std::any` para Cargas Útiles Genéricas

## Estado
Aceptado

## Contexto
El Bus de Eventos debe soportar la carga de cualquier tipo de dato (payloads). En C++, teníamos que elegir entre el uso de templates, herencia (una clase base común) o un contenedor de tipo seguro.

## Decisión
Hemos decidido utilizar `std::any` (introducido en C++17) para almacenar las cargas útiles de los eventos.

## Justificación
- **Flexibilidad**: `std::any` permite almacenar cualquier valor sin requerir que los datos hereden de una clase base común.
- **Seguridad de Tipos**: A diferencia de `void*`, `std::any` conserva la información del tipo y permite una conversión segura mediante `std::any_cast`.
- **Desacoplamiento**: El Bus de Eventos no necesita conocer los tipos de datos que transporta, cumpliendo así con el requerimiento de desacoplamiento.

## Consecuencias
- **Rendimiento**: Existe un ligero costo computacional debido a la asignación dinámica de memoria para objetos grandes.
- **Casteo**: Los suscriptores deben conocer el tipo esperado de la carga útil para realizar la conversión correctamente.
